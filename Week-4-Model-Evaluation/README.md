# Week 4 – Model Evaluation and Validation

## Overview

Week 4 focuses on evaluating and validating the Random Forest model developed for the UNSW-NB15 network intrusion detection project.

## Work Completed

- Train-test evaluation
- Accuracy, Precision, Recall, and F1-Score
- Confusion matrix analysis
- False Positive and False Negative analysis
- ROC-AUC evaluation
- ROC curve analysis
- Precision-Recall analysis
- 5-Fold Stratified Cross-Validation
- Overfitting analysis
- Week 3 vs Week 4 model comparison

## Model

Random Forest Classifier

## Key Results

| Metric | Score |
|---|---:|
| Accuracy | 97.63% |
| Precision | 98.44% |
| Recall | 97.24% |
| F1-Score | 97.84% |
| ROC-AUC | 99.71% |
| Mean CV F1-Score | 97.93% |
| CV F1 Standard Deviation | 0.07% |

## Conclusion

The Random Forest model achieved strong performance on the test dataset. Cross-validation also showed stable performance across folds. The evaluation results provide a baseline for Week 5 model optimization.
